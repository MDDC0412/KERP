# KERP

KERP 是一个面向 300+ 员工企业的本地优先 ERP 系统骨架，当前阶段已经落下组织、人事、权限、流程、审批、考勤、通知、审计、行政与资产、采购与库存、外部集成预留中心等核心模块，后续再继续进入财务等更完整 ERP 领域。

## 技术栈

- 后端：Java 17、Spring Boot 3.2.5、MyBatis-Plus、Flyway、MySQL 8
- 前端：Vue 3、TypeScript、Vite、Element Plus、ECharts
- 部署：本地开发优先，默认后端 `8080`、前端 `5173`

## 当前已落地模块

- 登录：本地登录接口、前端登录页、请求头会话注入
- 组织与人事：部门、员工、员工异动、入职计划、离职计划
- 用户与权限：系统账号、角色、权限、角色授权、数据权限
- 流程与审批：动态表单、流程定义、审批中心、审批待办、审批动作流转
- 考勤：班次、考勤组、排班、打卡记录、月汇总、按月生成汇总
- 通知：站内通知
- 外部集成：邮件、企业微信、飞书、钉钉、对象存储、AD/LDAP/SSO 的预留中心
- 审计：审计日志
- 行政与资产：资产分类、资产台账
- 采购与库存：供应商、采购订单、收货入库、库存台账、出库、调拨、盘点

## 当前目录

- `backend/`：后端工程
- `frontend/`：前端工程
- `docs/`：本地开发与外部服务预留说明

## 说明

- 本地开发必须使用 `JDK 17` 运行 Maven，不能让 Maven 挂在 `JDK 8` 上。
- 当前数据库迁移已经到 `V7`。
- 邮件、企业微信、飞书、钉钉、短信、域名、HTTPS 目前都不需要准备，只做了接口预留。
- 更详细的启动说明见 [docs/local-development.md](docs/local-development.md)。
