# 外部服务预留说明

当前版本优先保证本机最小可运行，因此默认不连接第三方平台，但相关能力已经按后续扩展方向预留。

系统内现已提供“外部集成”页面，可直接查看当前启用项、预留项和后续接入所需资源。

## 1. 通知能力

当前已落地：

- 站内通知

后续可接入：

- SMTP 邮件
- 企业微信消息
- 飞书消息
- 钉钉消息
- 短信服务

预留原则：

- 业务模块只产生通知事件
- 渠道模块负责真正发送
- 第三方渠道以后可按 provider 方式扩展

## 2. 身份与组织同步

当前已落地：

- 系统账号
- 角色
- 权限
- 数据权限

后续可接入：

- 企业微信登录与组织同步
- 飞书登录与组织同步
- AD / LDAP / SSO

预留原则：

- 内部用户模型不直接依赖外部平台字段
- 第三方身份通过映射关系接入
- 接入时不重做现有人事与权限模型

## 3. 文件存储

当前已落地：

- 本地磁盘目录预留

后续可接入：

- MinIO
- 其他对象存储
- 企业 NAS

预留原则：

- 业务层只依赖统一文件服务
- 存储实现可切换，不影响附件元数据结构

## 4. 供应链和消息联动预留

当前已落地：

- 采购与库存模块本地可运行
- 出库、调拨、盘点事件可继续向通知中心扩展

后续可接入：

- 飞书采购审批提醒
- 企业微信到货通知
- 邮件库存预警

预留原则：

- 先保证库存业务链路闭环
- 外部产品只作为通知和同步增强层
- 不把第三方平台做成主业务依赖

## 5. 当前你不需要准备的资源

此阶段不需要准备：

- 邮件服务账号
- 企业微信开放平台资源
- 飞书开放平台资源
- 短信平台账号
- 域名
- HTTPS

等我们推进到对应模块时，我再明确告诉你要准备哪些账号、密钥、回调地址和配置项。
